# Changelog

## Sprint 1

- Added a database to save user data.

- Added account creation and logging in.

- Added a homepage.

- Added a button and page to create a group.

## Sprint 2

- Added a welcome screen.

- Added a group page.

- Added a tasks page.

- Added Submission and Validation pages.

# Sprint 3

- Added a profile page where the user is able to edit it and log out of their account.

- It is now possible to search for other users and see their profile and what circles they participate in.

- Now you can't submit more than one time in each task.

- All code was refactored so that screens no longer access the database directly; instead, data is first processed through the models.

- Now each group has a daily task which switches every day according to UTC time.

- There are also 3 group themes with different tasks.
